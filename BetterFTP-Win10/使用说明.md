# BetterFTP 使用说明（老师版）

BetterFTP 是给老师用的课件传输小工具：**点自己的账号 → 自动连接 → 上传/下载课件**，不需要记地址和密码。

## 一、第一次使用

1. 把 `BetterFTP` 文件夹整个放到 **D 盘**（例如 `D:\BetterFTP`）。
   > 为什么放 D 盘：班级电脑 C 盘装有冰点还原，重启后 C 盘的新文件会消失；D 盘不会。配置文件保存在程序旁边的 `data` 文件夹里，放 D 盘才能记住账号。
2. 双击 `BetterFTP-Portable-1.0.0.exe`（绿色免安装，不需要管理员权限）。
3. 点左下角 **⚙ 设置 → 账号管理 → ＋ 添加账号**：
   - **显示名称**：自己的名字，如「张老师」
   - **FTP 用户名 / 密码**：服务器分配的账号
   - **默认打开路径**：点「浏览…」选到自己的课件文件夹（也可以不选，默认根目录）
   - 可选：标记颜色、备注（如「高一(3)班 数学」）
   - 点 **🔌 测试连接** 确认账号可用，然后 **保存**。

> 换电脑或重装系统：设置里 **导出配置备份** 存到 U 盘，新电脑上 **导入配置备份** 即可恢复全部账号。

## 二、日常使用

| 想做什么 | 怎么做 |
|---|---|
| 进入自己的文件夹 | 点左侧自己的账号卡片，自动连接并打开 |
| 上传课件 | 点 **⬆ 上传文件**（默认从桌面选文件），选好后自动开始传输 |
| 下载课件 | 在列表**单击选中**文件 → 点 **⬇ 下载**，保存到桌面 |
| 打开课件 | **双击**文件：自动下载到桌面并打开 |
| 进入文件夹 | 双击文件夹；**面包屑路径**可以快速跳回上级 |
| 搜索 | 右上角搜索框，在当前文件夹内查找 |
| 返回上级 | 顶栏「↑ 上级」按钮 |
| 看传输进度 | 底部传输队列：进度、速度、剩余时间；失败了点 **重试** |

### 文件夹权限

文件夹顶栏有权限标记：

- **读写**（绿）：全部功能可用
- **只读**（橙）：只能看和下载，上传/删除按钮自动变灰
- **只写**（橙）：投递箱——只能往里传，看不到里面的内容

### 同名文件怎么办

上传/下载遇到同名文件时，会弹出选择：**覆盖 / 重命名保留两者（自动加编号）/ 跳过**。删除操作需要二次确认。

### 传输出问题

报错会写清原因和解决办法，常见情况：

- **账号或密码错误（530）**→ 去设置核对用户名密码（区分大小写）
- **端口不通 / 连接超时** → 确认网线连好、校园网可达、服务器开机
- **数据通道被防火墙拦截** → 设置里把「被动模式」关掉改主动，或联系网管
- **连接数超限（421）** → 你可能在别的电脑上也开着；等一分钟，或在设置里把「同时传输数」调小
- **文件名乱码** → 设置里把编码改成 GBK（或换回 UTF-8）

## 三、给管理员的说明

- 程序默认服务器：`10.180.168.3:21`（可在「设置 → 全局」修改）。
- 配置文件位置：程序目录旁 `data\config.json`（便携模式，跟程序走）。
- 操作日志：`data\logs\年-月.jsonl`，设置里可查看、导出 CSV、清空，保留 6 个月。
- 密码以明文保存在本机配置中（学校场景权衡后的选择），请勿把 `data` 文件夹外传。

## 四、自定义界面文字（给管理员）

所有界面文字集中在源码的 `src/renderer/src/texts.js`（错误提示在 `src/main/texts.js`），改后运行 `npm run build:portable` 重新打包生效。

**免打包微调**：在程序旁的 `data` 文件夹新建 `文案覆盖.json`，只写要改的条目，重启程序即生效。例如：

```json
{
  "actions": { "upload": "传课件" },
  "perms": { "ro": { "text": "只读（校供）" } }
}
```

删除该文件即恢复默认文字。分节含义：`actions` 操作按钮、`perms` 权限徽章、`top` 顶栏、`table` 列表与行内按钮、`empty` 空状态、`dock` 传输队列、`dialog` 弹窗、`settings` 设置页。
